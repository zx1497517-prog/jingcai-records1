# 我的竞彩足球记录

个人使用的竞彩足球（胜平负单关）记录网页。

## 功能
- 记录投注：比赛、选择（胜 / 平 / 负）、赔率、金额
- 比赛结算：输入或自动获取赛果，自动判中奖、算盈亏
- 历史统计：总投注、总盈亏、胜率
- 自动获取真实比分（TheSportsDB，需联网）

## 技术说明
- 单文件纯前端：HTML + CSS + JavaScript，全部在 `index.html` 里
- 数据保存在浏览器 localStorage（仅本机，关掉网页再打开还在）
- 无后端、无数据库、无需登录
- 本项目当前为 localStorage 版本；多人云同步为后续计划

## 部署
本仓库通过 GitHub Pages 静态托管，访问仓库对应的 Pages 网址即可使用。
